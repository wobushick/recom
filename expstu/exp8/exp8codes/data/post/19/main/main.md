# 量子计算入门：从薛定谔的猫到量子霸权

## 经典比特 vs 量子比特

经典计算机的最小信息单位是比特（0 或 1）。量子比特（qubit）却可以同时处于 0 和 1 的叠加态。这个听起来像哲学概念的性质，是量子计算力量的来源。2 个量子比特可以同时表示 4 种状态，300 个量子比特可以表示的状态数超过了可观测宇宙中的原子总数。

## 量子优势的证明

2019 年，Google 的 Sycamore 处理器用 200 秒完成了一项计算——这项计算在当时最强大的经典超级计算机上需要约 1 万年。虽然 IBM 后来提出了争议（认为经典算法可以在 2.5 天内完成），但这个里程碑标志着量子计算从理论走向了工程验证。

## 主要应用领域

量子计算不是"加速一切"的魔法棒。它有特定的杀手应用：密码学（Shor 算法可以在多项式时间内分解大整数，威胁 RSA 加密体系）、量子化学（模拟分子结构是经典计算无法精确完成的任务）、优化问题（从供应链物流到金融组合优化）。

## 当前挑战

量子比特极其脆弱，任何微小的环境噪声（温度波动、电磁干扰）都会导致量子退相干。今天的量子处理器需要接近绝对零度（-273°C）才能运行。错误纠正和容错量子计算仍是通往实用化的最大障碍。
