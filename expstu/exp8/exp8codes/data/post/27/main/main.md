# 云南旅行记：在大理的云下

## 为什么是云南

云南是中国地貌最丰富的省份——从梅里雪山的冰川到西双版纳的热带雨林，从香格里拉的高原草甸到元阳的哈尼梯田。每个地方都像另一个世界，而它们之间的距离往往只有几个小时车程。

## 大理：时间变慢的地方

大理古城有一种奇特的氛围。苍山的雪水流过街道，白族的老人坐在石阶上晒太阳，洱海的风穿过咖啡馆的帘子。这里聚集了逃离城市的人——辞职的程序员开了面包店，前金融分析师做了皮具匠人。他们在那里不是"躺平"，而是选择了一种自己定义的生活方式。

## 沙溪古镇

距大理三小时车程的沙溪曾是茶马古道上最后一个驿站。古镇保留了完整的明清建筑群，青石板路上的马蹄印至今可辨。每个周五，周边的彝族和白族村民会来赶集，背篓里装着松茸、野生蜂蜜和手工染布——这个集市已经持续了 600 年。

## 食物与人

云南的美食跟它的人口一样多元。过桥米线的热汤上浮着一层鸡油，保住了所有食材的温度和鲜味。傣族的香茅草烤鱼、纳西族的腊排骨火锅、藏区的酥油茶——每一种味道都告诉你：你到了一个新的地方，而这个新地方有着悠久的传统。
