# AI 大模型时代：2024-2025 关键进展

## 从 ChatGPT 到多模态

2022 年底 ChatGPT 横空出世后，AI 领域进入了前所未有的加速期。截至 2025 年，主要进展包括：Gemini 的多模态原生能力，文本图像视频一体化理解；Claude 的长上下文突破，200K token 让整本书级别的分析成为可能；开源模型的崛起，Llama 3 和 Qwen 等模型缩小了与闭源模型的差距。

## Agent 与工具使用

AI Agent 是 2024-2025 年最火热的方向。模型不再只是"对话机器人"，而是能够使用浏览器、编写代码、查询数据库、调用 API 的自主智能体。这标志着 AI 从"回答问题"进化到了"执行任务"。

## RAG 与知识增强

检索增强生成（RAG）技术解决了大模型的幻觉问题和知识截止日期的限制。企业可以将内部文档向量化存储，当用户提问时实时检索相关信息再交给模型生成答案——这在客服、法律、医疗等垂直领域掀起了应用浪潮。

## 算力与成本

训练 GPT-4 级别的模型需要上亿美元的计算资源。但推理成本的快速下降（部分模型 API 价格在一年内下降了 90% 以上）让 AI 真正进入了千万应用阶段。小型模型的惊人表现也在挑战"更大即更好"的假设。
